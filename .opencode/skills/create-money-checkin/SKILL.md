# Create Money Check-In

Create a short, repeatable money review that helps the user stay aware without
feeling judged.

## When to use this

Use this skill when the user asks for:

- a weekly money check-in
- a monthly spending review
- a simple budget reflection
- a plan for next week
- help staying on top of money

## Procedure

1. Recall any existing money goals, fixed costs, subscriptions, or spending
   patterns from memory.
2. Ask for missing numbers only if needed:
   - money available this week/month
   - fixed costs due
   - savings goal
   - known upcoming costs
3. Build a short check-in with:
   - what came in
   - what went out
   - what is still upcoming
   - one thing to watch
   - one small action
4. Offer to save the check-in summary to memory if the user wants.

## Output format

```markdown
## Money Check-In

Available now: <amount or unknown>
Upcoming fixed costs: <amount or unknown>
Main pressure point: <category or unknown>

## This Week's Focus

<one calm sentence>

## Tiny Action

<one specific action>
```

## Guidance

- Keep it short.
- Do not produce a strict budget unless the user asks.
- Focus on awareness and one next action.
